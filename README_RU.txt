BEAUTIFUL WAVES 1.0.2 — Fabric / Minecraft Java 1.20.1

Клиентский Fabric-мод: анимирует верхнюю геометрию отрисовываемой воды.
Это не ресурспак и не шейдер. Физической симуляции, частиц и фоновых потоков нет.

ИСПРАВЛЕНИЯ 1.0.2
- Исправлена сигнатура обработчика @ModifyArgs: принимает только Args.
- Контекст текущего блока воды передаётся через HEAD/RETURN-инъекции.
- Лава не анимируется.
- Используется таблица синуса из 1024 значений.
- Если сторонний рендерер меняет FluidRenderer, конфигурация Mixin не должна
  принудительно останавливать запуск игры; в таком случае эффект может не включиться.

СОВМЕСТИМОСТЬ
- Minecraft Java 1.20.1, Fabric Loader 0.15.11+, Java 17.
- Клиентская сторона; серверу мод не нужен.
- PojavLauncher: используй профиль Fabric 1.20.1 и Java 17.
- Не требует Iris, Sodium или шейдеров. Sodium/Embeddium-подобные моды могут
  заменить путь рендеринга; совместимость с конкретной сборкой не проверена.
- На Pojav нет гарантии 60 FPS: результат зависит также от GPU/драйвера и температуры.

СБОРКА
Нужны JDK 17 и Gradle 8.6:
  gradle build
JAR появится в build/libs/beautiful-waves-1.0.2.jar

УСТАНОВКА
Скопируй только beautiful-waves-1.0.2.jar в папку mods того профиля Pojav,
который запускает Fabric для Minecraft 1.20.1.

ПРОВЕРКА
Проект содержит исходники и конфигурацию сборки. Готовый JAR не приложен:
в текущей среде отсутствует Gradle и невозможно получить зависимости сборки.
Не переименовывай ZIP в JAR и не клади ZIP в mods.


Версия 1.1.0: добавлен необязательный Mixin для Sodium 0.5.x,
нацеленный на FluidRenderer.fluidCornerHeight. Он меняет высоту
углов поверхности воды двумя малoамплитудными волнами.
Важно: сборка и запуск на Minecraft ещё не проверены; это исходный
проект для тестирования, а не подтверждённый готовый JAR.
